300 cross-split pairs of PPE-Unified v1 drawn at random (seed 42) from the 8109 FAISS top-5 pairs with cosine in [0.95, 0.98].
Label each row of validation_300.csv: dup_copy (same photo, edited), dup_scene (same camera/scene, different moment), not_dup.
This is a validation set for the copy-level operating point, not used for calibration.
